米槠-栲群团

Castanopsis carlesii - C. fargesii All.


米槠-栲林（Source: EBLF）

湖南会同栲林（Source: EBLF）


优势种：

  • 栲(Castanopsis fargesii)、米槠(Castanopsis carlesii)


鉴别种和主要伴生种:

  • 杜茎山（Maesa japonica）、朱砂根（Ardisia crenata）、草珊瑚（Sarcandra glabra）、狗脊（Woodwardia japonica）等


(a) 米槠-栲树群团-江南丘陵群丛组

主要分布在浙江、湖南丘陵低山地区。伴生种除群团的鉴别种外，乔木层常见的有：赤楠（Syzygium buxifolium）、马银花（Rhododendron ovatum）、南烛（Vaccinium bracteatum）、杨梅（Myrica rubra）、浙江新木姜子（Neolitsea aurata var. chekiangensis）、黄丹木姜子（Litsea elongata）、络石（Trachelospermum jasminoides）等，分布范围较偏北


目前包含2个群丛和4个群落

  • (A1) 尖连蕊茶-浙江新木姜子/米槠群丛(Camellia cuspidata-Neolitsea aurata var. chekiangensis / Castanopsis carlesii Ass.)

    分布在浙江杭州（EBLF书中表5-66；曾称：杜茎山-浙江新木姜子∕米槠群丛)

  • (A2) 毛柄连蕊茶-浙江新木姜子/栲-米槠群丛(Camellia fraterna-Neolitsea aurata var. chekiangensis / Castanopsis fargesii-Castanopsis carlesii Ass.)

    分布在浙江宁波，引自：《天童植被与区系》中的“木荷ʹ栲群丛”（宋永昌和王祥荣，1995）（EBLF书中表5-67，EBLF书中表5-56，EBLF书中表5-57; 曾称：毛柄连蕊茶-浙江新木姜子/栲树群丛，毛柄连蕊茶-浙江新木姜子/米槠群丛，两者合并)

  • (C1）穗序鹅掌柴-利川润楠/米槠群落(Heptapleurum delavayi-Machilus lichuanensis / Castanopsis carlesii Comm.)

    分布在湖南慈利（EBLF书中表5-70; 曾称：穗序鹅掌柴-黄杞∕米槠群落)

  • (C2) 石南藤-毛豹皮樟-湘楠/栲群落（Piper wallichii-Litsea coreana var. lanuginosa-Phoebe hunanensis / Castanopsis fargesii Comm.）

    分布在湖南会同(EBLF书中表5-59/1) (曾称：毛豹皮樟∕栲树群落)

  • (C3) 粉叶首冠藤-毛豹皮樟/青冈-栲群落（Cheniella glauca-Litsea coreana var. lanuginosa / Quercus glauca-Castanopsis fargesi Comm.）

    分布在湖南会同(EBLF书中表5-59/2; 曾称：毛豹皮樟∕栲树群落)

  • (C4) 尖连蕊茶/钩锥-栲群落（Camellia cuspidata / Castanopsis tibetana-Castanopsis fargesi Comm.）

    分布在湖南会同。引自：《湖南植被》中 “栲树、钩锥群落”（祁承经，1990）(EBLF书中表5-60) (曾称：杜茎山-钩锥/栲树群落)


(b) 米槠-栲树群团-南岭山地群丛组

主要分布在福建、广东、江西等地丘陵山地。伴生种除群团的鉴别种外，常见的还有：黄杞（Engelhardia roxburghiana）、日本杜英（Elaeocarpus japonicus）、杨桐（Adinandra millettii）、鹅掌柴（Heptapleurum heptaphyllum）、九节（Palicourea hoffmannseggiana）、虎舌红（Ardisia mamillata）、流苏子（Coptosapelta diffusa）等，相对于江南丘陵群丛组立地条件更温暖湿润。


目前包括1个群丛和8个群落

  • (A1) 黑莎草-轮叶蒲桃/栲-米槠群丛(Gahnia tristis-Syzygium grijsii / Castanopsis fargesii-Castanopsis carlesii Ass.)

    分布在福建梁野山、天宝岩、梅花山，引自：《福建天宝岩自然保护区综合科学报告》（林鹏 等，2002），《福建梁野山自然保护区综合科学报告》（林鹏 等，2001），《福建梅花山自然保护区植被》（邱喜昭，1988），（EBLF书中表5-68; 曾称：轮叶蒲桃-少叶黄杞∕米槠群丛)

  • (C1) 乌毛蕨-毛柄连蕊茶-鹅掌柴/栲-米槠群落(Blechnum orientale-Camellia fraterna-Heptapleurum heptaphyllum / Castanopsis fargesii-Castanopsis carlesii Comm.)

    分布在福建莆田南昆山(EBLF书中表8-26∕1；曾称：：九节木-鹅掌柴∕米槠群落，现从其中分出)

  • (C2) 鳞籽莎-面竿竹-鹅掌柴/栲群落(Lepidosperma chinense-Pseudosasa orthotropa-Heptapleurum heptaphyllum / Castanopsis fargesii Comm.)

    分布在福建莆田南昆山 (EBLF书中表8-26∕2；曾称：：九节木-鹅掌柴∕米槠群落，现从其中分出)

  • (C3) 金毛狗-白花灯笼-鹅掌柴/栲树群落（Cibotium barometz-Clerodendrum fortunatum-Heptapleurum heptaphyllum / Castanopsis fargesii Comm.）

    分布在福建莆田、南靖。引自：《福建植被》中“米槠+栲树-九节木+百两金+连蕊茶-狗脊+里白群丛”（林鹏，1990）。 (EBLF书中表8-26/3；曾称：九节木-鹅掌-鹅掌柴/栲树-米槠群落)

  • (C4) 钩毛草-山牡荆-九节/栲群落（Pseudechinolaena polystachya-Vitex quinata-Palicourea hoffmannseggiana / Castanopsis fargesi Comm.）

    引自：《福建植被》（林鹏，1990)一书中的“栲树＋山杜英-九节木-狗脊群丛”，分布在福建莆田 (EBLF书中表5-58/1；曾称：九节木-黄杞∕栲树群落，现从其中分出)

  • (C5)心叶毛蕊茶-阔瓣含笑/栲群落(Camellia cordifolia-Magnolia cavaleriei var. platypetala / Castanopsis fargesii Comm. )

    分布在江西井冈山。引自：《江西植被的基本类型》（林英，1977）和《江西森林》（江西森林编委会，1986) 中所记载的 “狗脊-细枝柃-丝栗锥林型”的综合(EBLF书中表5-58/2；曾称：：九节木-黄杞/栲树群落，现从其中划分出来)

  • (C6) 箬竹-鹿角杜鹃-翻白叶树/米槠群落(Indocalamus tessellatus-Rhododendron latoucheae-Pterospermum heterophyllum / Castanopsis carlesii Comm. )

    分布在江西九连山（EBLF书中表5-69/1；曾称：草珊瑚-黄杞/米槠群落，现从其中分出)

  • (C7）四川冬青-香花枇杷/米槠群落(Ilex szechwanensis-Eriobotrya fragrans / Castanopsis carlesii Comm. )

    分布在江西九连山（EBLF书中表5-69/2；曾称：草珊瑚-黄杞∕米槠群落，现从其中分出)

  • (C8) 林仔竹-红花荷/甜槠-米槠群落(Oligostachyum nuspiculum-Rhodoleia championi / Castanopsis eyrei-Castanopsis carlesii Comm.)

    分布在广东南昆山。(EBLF书中表8-25；曾称：红花荷/甜槠-米槠群丛)


(c) 米槠-栲树群团-黔桂山地群丛组

主要分布在广西和贵州东部等地。伴生种除群团的鉴别种外，常见的还有：黄杞（Engelhardia roxburghiana）、日本杜英（Elaeocarpus japonicus）、杨桐（Adinandra millettii）、鹅掌柴（Heptapleurum heptaphyllum）、九节（Palicourea hoffmannseggiana）、虎舌红（Ardisia mamillata）、流苏子（Coptosapelta diffusa）等，相对于江南丘陵群丛组立地条件更温暖湿润


目前包含4个群丛和20个群落

  • (A1) 鳞毛蕨-多花杜鹃/栲群丛 (Dryopteris erythrosora-Rhododendron cavaleriei ∕ Castanopsis fargesii Ass.)

    分布在广西龙胜、兴安、贺县。引自:《广西栲树林分类的研究》一文中的“栲树-岩杜鹃(鹿角杜鹃)-杜茎山-狗脊群丛”、“栲树-羊角杜鹃(多花杜鹃)-杜茎山-狗脊群丛”和“栲树-毛叶木姜(黄丹木姜子)-杜茎山-狗脊群丛” 王献溥等(2005b)三者的综合(EBLF书中表5-64∕1-3; 曾称: 穗序鹅掌柴-多花杜鹃/栲树群丛)

  • (A2) 东方古柯-西藏山茉莉/栲群丛 (Erythroxylum sinense-Huodendron tibeticum / Castanopsis fargesii Comm.)

    分布在广西阳朔碎江。引自:《广西栲树林分类的研究》一文中的“栲树-毛叶木姜(黄丹木姜子)-粗叶木-金毛狗＋狗脊群丛”、“栲树-细枝柃-杜茎山-狗脊群丛”, 以及“栲树＋细枝锥(米槠)-鼠刺＋凹脉柃-杜茎山-狗脊群丛”王献溥等(2005b), 三者综合(EBLF书中表5-64∕7-9; 曾称: 岭南杜鹃-硬壳桂∕栲树群丛)

  • (A3) 乌毛蕨-鹅掌柴/栲群丛 (Blechnum orientale-Heptapleurum heptaphyllum / Castanopsis fargesii Comm.)

    分布在广西贺县滑水冲、阳朔大水田 (EBLF书中表5-64∕10; 曾称: 鸡骨香-甜槠∕栲树群丛, EBLF书中表5-64∕5-6, 书中未命名), 此外分布在三江合流处(W栲14: W5.29-30)

  • (A4) 广东杜鹃-尖叶川杨桐∕栲树群丛 (Rhododendron kwangtungense-Adinandra bockiana var. acutifolia ∕ Castanopsis fargesii Ass.)

    分布在广西贺县。引自: 《广西栲树林分类的研究》一文中的 “栲树-广东杜鹃-梅叶冬青(Ilex asprella)-狗脊群丛”、“栲树-黄樟(Cinnamomum parthenoxylum)-九节风(草珊瑚)-狗脊群丛”和 “栲树-尖叶川杨桐(Adinandra bockiana var. acutifolia)-梅叶冬青-狗脊群丛” 王献溥等(2005), 三者综合而成 (EBLF书中表5-64∕4-6; 曾称: 鹅掌柴-刨花润楠∕栲树群丛)

  • (C1) 短梗大参-厚叶鼠刺∕米槠群落 (Macropanax rosthornii-Itea coriacea∕ Castanopsis carlesii Comm.)

    分布在广西龙胜花坪 (EBLF书中表5-71/1~2) (原名: 短梗大参-厚叶鼠刺∕米槠群丛)

  • (C2) 背囊复叶耳蕨-落地紫金牛/米槠群落 (Arachniodes cavalerii-Ardisia primulifolia ∕ Castanopsis carlesii Comm.)

    分布在广西龙胜花坪 (W米槠2, 表5: 41-42)

  • (C3) 淡竹叶-灰背清风藤/米槠群落 (Lophatherum gracile-Sabia discolor ∕ Castanopsis carlesii Comm.)

    分布在广西龙胜花坪 (W米槠6, 表5: 51-52)

  • (C4) 铁芒萁-少花柏拉木/米槠群落 (Dicranopteris linearis-Blastus pauciflorus ∕ Castanopsis carlesii Comm.)

    分布在广西阳朔兴坪 (EBLF书中表5-71/4) (原名: 短梗大参-厚叶鼠刺∕米槠群丛) (W米槠5, 表5: 49-50)

  • (C5) 半柱毛兰-广东杜鹃/米槠群落 (Eria scabrilinguis-Rhododendron kwangtungense ∕ Castanopsis carlesii Comm.)

    分布在广西阳朔兴坪(EBLF书中表5-71/3, 原名: 十字薹草-江南越桔∕米槠群丛) (W米槠5, 表5: 49-50)

  • (C6) 锦香草-鹿角杜鹃/米槠群落 (Phyllagathis cavaleriei-Rhododendron latoucheae / Castanopsis carlesii Comm.)

    分布在广西龙胜里骆 (W米槠4, 表5: 47-48)

  • (C7) 江南短肠蕨-柏拉木/米槠群落 (Diplazium mettenianum-Blastus cochinchinensis / Castanopsis carlesii Comm.)

    分布在广西龙胜 (W米槠8, 表5: 55-56)

  • (C8) 山菅兰-柏拉木/米槠群落 (Dianella ensifolia-Blastus cochinchinensis / Castanopsis carlesii Comm.)

  • (C9) 倒挂铁角蕨-岭南杜鹃/米槠群落 (Asplenium normale-Rhododendron mariae / Castanopsis carlesii Comm.)

  • (C15) 锦香草-棱果花/栲群落 (Phyllagathis cavaleriei-Barthea barthei / Castanopsis fargesii Comm.)
